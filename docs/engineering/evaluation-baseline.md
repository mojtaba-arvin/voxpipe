# Evaluation Baseline — Engineering Document

## Scope and Constraints

Hard constraints for this work:

- Single agent session. No local machine.
- No \`gh\` CLI. Use \`curl\` + GitHub REST API.
- No paid or non-free APIs. No external inference APIs.
- Only GitHub Actions as execution environment.
- Content examples must be safe for sales and future medical use.

Goal is **not** to close Issues #32, #48, #47 definitively.
Goal is to produce an **automated, reproducible, auditable silver
baseline** and to document its methodological limits.

## Issue Status

These are **quality evidence gaps**, not blocking bugs. The VoxPipe
README itself acknowledges that no Persian gold set with human
review and no human relevance scores exist yet.

| Issue | Nature | Automation boundary |
|-------|--------|---------------------|
| #32   | Extraction evidence gap | Deterministic rules + templates → **silver**, not gold |
| #48   | Retrieval evidence gap  | Heuristic qrels → **silver**, not human judgment |
| #47   | Test-condition gap      | Only **read-speech** (Common Voice) or **synthetic**; not natural conversation |

Priority: **#32 → #48 → #47**. #32's transcript output is #48's
corpus. #47 is the most expensive and most compliance-sensitive.

## GitHub Actions as Execution Environment

### Issue comment without \`gh\`

workflow permissions:

    permissions:
      contents: read
      issues: write

comment via REST API:

    - name: Comment on issue
      run: |
        curl -s -X POST \
          -H "Authorization: Bearer \${{ secrets.GITHUB_TOKEN }}" \
          -H "Accept: application/vnd.github+json" \
          "https://api.github.com/repos/\${{ github.repository }}/issues/32/comments" \
          -d '{"body":"**Automated silver baseline generated.** Limitations: synthetic/template data, no human annotator."}'

\`GITHUB_TOKEN\` has write access only if \`issues: write\` is declared
in the \`permissions\` block.

### Models and tools (free, CPU-friendly)

| Use                | Choice                  | Evidence / reason |
|--------------------|-------------------------|-------------------|
| Multilingual ASR + LID | Qwen3-ASR-0.6B      | 52 languages incl. **Persian (fa)**; native language ID; usable on fa, lower accuracy than 1.7B |
| Lightweight LID    | ECAPA-TDNN LID (GGUF)   | 21M params / 40 MB, Apache 2.0, includes Persian |
| Alignment + diarization | WhisperX           | \`--compute_type int8\`, batch 1–4; slow on CPU, use only for alignment, not main ASR |
| LLM judge / RAG    | \`LLM-as-Judge\` (Ollama or offline mock) | Cohen's kappa; inter-LLM agreement ~0.61 (moderate) in independent studies |

### Hardware limit

GitHub Actions free runner: ~2 CPU cores, 7–14 GB RAM.
Qwen3-ASR-0.6B and ECAPA-LID are realistic. Whisper large is not.
WhisperX runs with \`--batch_size 1 --compute_type int8\` and only for
alignment/diarization.

## Issue #32 — Silver Extraction Baseline

- Input: templates + random slots → sales/support conversations.
  No medical content. Names/phones/addresses as placeholders.
- Labels: regex + deterministic rules for structured fields (date,
  amount, order id) → \`silver_gold.jsonl\`. Free-text fields = null
  or ambiguous.
- Evaluation: VoxPipe extraction vs silver gold → Precision / Recall
  / F1 at micro and macro.
- Report line: \`Silver standard generated by deterministic rules;
  no human annotator.\`

## Issue #48 — Silver Retrieval Baseline

- Corpus: from #32 (or placeholder until ready).
- Query: 100–200 Persian queries with source passage ID.
- Qrels: source = relevant (2); high lexical overlap = partially
  relevant (1); else irrelevant (0).
- Metrics: Recall@5, MRR, nDCG@5; 70/15/15 split; fixed seed.

## Issue #47 — Two Restricted Branches

Branch A — read-speech, open license:
- Mozilla Common Voice Persian (CC0). v27.0 = 431.44 h recorded
  (373.15 h validated), 4,668 speakers. Transcribe with Qwen3-ASR
  or WhisperX. Label: read-speech, no overlap.

Branch B — synthetic "conversational":
- TTS on #32 text + \`ffmpeg\` for pauses/noise/controlled overlap.
  Ground-truth overlap and speaker are exact.
- Label: synthetic, not natural.

Out of scope: real natural audio collection with consent. Requires
compliance review and human oversight. Not automated here.
